# 📐 UML Editor (Java)

The UML Editor is a full-featured Java application designed for creating and managing UML diagrams. The project emphasizes **object-oriented design**, **maintainability**, and **extensibility**, making it easy to enhance with new diagram types and features.

---

## 🚀 Features

- ✏️ Create and edit UML diagrams
- 🔄 Real-time updates using the Observer design pattern
- 🧱 Strong object-oriented design
- 🔧 Easily maintainable and extensible codebase
- 📦 Modular and scalable architecture

---

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Observer Design Pattern

---

## 🏗️ Architecture & Design

### Object-Oriented Design
- Clear separation of responsibilities
- High cohesion and low coupling
- Reusable and testable components

### Observer Design Pattern
- Ensures automatic updates when diagram elements change
- Decouples UI components from underlying model logic
- Improves scalability and maintainability

---

## 🔌 Extensibility

- New UML diagram types can be added with minimal changes
- Observers can be extended to support additional views or exports
- Core logic remains unchanged when introducing new features
